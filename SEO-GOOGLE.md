## 2. Ajouter le site à Google Search Console

1. Se connecter à <https://search.google.com/search-console/> avec le compte
   Google du cabinet.
2. Cliquer sur **Ajouter une propriété**.
3. Choisir **Préfixe de l’URL**.
4. Saisir exactement :

   `https://legalitymg.github.io/`

5. Choisir la méthode **Balise HTML**.
6. Copier la valeur située dans :

   `<meta name="google-site-verification" content="VALEUR_A_COPIER" />`

7. Ajouter cette valeur au code du site, publier la mise à jour, puis revenir
   dans Search Console et cliquer sur **Valider**.

Ne transmettre que la valeur de vérification. Ne jamais transmettre de mot de
passe ni de code de connexion.

## 3. Envoyer le sitemap

Après validation de la propriété :

1. ouvrir **Indexation → Sitemaps** ;
2. saisir `sitemap.xml` ;
3. cliquer sur **Envoyer** ;
4. vérifier que l’état devient **Opération effectuée**.

Adresse complète :

`https://legalitymg.github.io/sitemap.xml`

Dans Search Console, consulter :

- **Performances** : requêtes, clics, impressions et position moyenne ;
- **Indexation des pages** : pages indexées et erreurs ;
- **Sitemaps** : dernière lecture par Google ;

Le référencement n’est pas instantané et aucune première position ne peut être
garantie. Le site doit d’abord être exploré et indexé, puis gagner en pertinence
locale et en notoriété.
